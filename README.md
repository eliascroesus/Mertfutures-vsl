# Mert Futures VSL

Source material for editing Mert's VSL. Everything apart from `mert-raw-vsl-footage/` was copied over from
[rickyvsl-clips](https://github.com/eliascroesus/rickyvsl-clips) (Ricky's VSL), including the Iman Gadzhi and
AB Nasdaq reference VSL breakdowns in [`01-vsls/reference-vsls/`](01-vsls/reference-vsls/).

**Mert's raw VSL video goes in the [Mert raw VSL release](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=mert-raw-vsl&title=Mert%20raw%20VSL)**
(see [`mert-raw-vsl-footage/`](mert-raw-vsl-footage/)).

| Folder | What goes in it |
| --- | --- |
| [`mert-raw-vsl-footage/`](mert-raw-vsl-footage/) | **Mert's** raw, unedited VSL recording (the one we're editing) |
| [`01-vsls/`](01-vsls/) | Ricky's current VSL (`current-vsl/`) and example VSLs to learn from (`reference-vsls/`, broken down in [BREAKDOWN.md](01-vsls/reference-vsls/BREAKDOWN.md)) |
| [`02-results-and-b-roll/`](02-results-and-b-roll/) | Everything else, all in one place: results, testimonials, B-roll, photos, journey pictures, context (mapped in [ASSET-MAP.md](02-results-and-b-roll/ASSET-MAP.md)) |
| [`03-raw-vsl-footage/`](03-raw-vsl-footage/) | Ricky's raw VSL recording and its transcript (copied over; not Mert's) |

## Uploading

**Pictures, screenshots and small files (under 25 MB):** open the folder on GitHub, click
**Add file → Upload files**, drag the files in and click **Commit changes**.

**Videos (up to 2 GB each):** these go in a GitHub Release, which takes big files straight from the browser.
There's one release per folder. Open its link (if GitHub asks about the tag, pick **Create new tag … on publish**),
drag the videos into the box at the bottom ("Attach binaries"), wait until every file has finished uploading,
then click **Publish release**:

| Videos | Upload link |
| --- | --- |
| **Mert raw VSL** | [releases/new?tag=mert-raw-vsl](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=mert-raw-vsl&title=Mert%20raw%20VSL) |
| Current VSL | [releases/new?tag=current-vsl](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=current-vsl&title=Current%20VSL) |
| Reference VSLs | [releases/new?tag=reference-vsls](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=reference-vsls&title=Reference%20VSLs) |

To add more videos to a release later, open it under **Releases**, click the pencil (Edit), attach the
files and click **Update release**. Files over 2 GB need to be split or exported smaller first.
