# Mert raw VSL footage

The raw, unedited recording of Mert's VSL that we're going to edit.

**Upload it here (up to 2 GB per file):**
[Mert raw VSL release](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=mert-raw-vsl&title=Mert%20raw%20VSL)

1. Open the link. If GitHub asks about the tag, pick **Create new tag: mert-raw-vsl on publish**.
2. Drag the video into the box at the bottom ("Attach binaries by dropping them here").
3. Wait until the upload bar has finished, then click **Publish release**.

If it was recorded in several takes or with separate audio, upload every file and note the order in a
`notes.md` here. Files over 2 GB need to be split or exported smaller first.

To add more files later, open the release under **Releases**, click the pencil (Edit), attach the files
and click **Update release**.
