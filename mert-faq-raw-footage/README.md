# Mert FAQ raw footage

Mert's raw, unedited FAQ videos (one video per question).

**Upload here (up to 2 GB per file):**
[Mert FAQ raw footage release](https://github.com/eliascroesus/Mertfutures-vsl/releases/new?tag=mert-faq&title=Mert%20FAQ%20raw%20footage)

1. Open the link. If GitHub asks about the tag, pick **Create new tag: mert-faq on publish**.
2. Drag the videos into the box at the bottom ("Attach binaries by dropping them here").
3. Wait until every upload bar has finished, then click **Publish release**.

Name each file after its question if you can (for example `how-much-time.mov`, `is-it-for-beginners.mov`),
so it's clear which answer is which.

To add more files later, open the release under **Releases**, click the pencil (Edit), attach the files and click
**Update release**. Files over 2 GB need to be split or exported smaller first.
